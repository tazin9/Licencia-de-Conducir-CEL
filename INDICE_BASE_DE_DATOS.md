# Índice Geral da Base de Dados Normativa – Médico Examinador (CEL Avellaneda / PBA)

Este repositório reúne todas as leis, decretos, disposições da Agencia Nacional de Seguridad Vial (ANSV), manuais de avaliação psicofísica (baremos), resoluções da Província de Buenos Aires e normas de blindagem médico-legal necessários para o exercício da função de **Médico Examinador** nos Centros Emisores de Licencias de Conducir (CEL).
